# 이번 주말 컨디션 (날씨·특보·미세먼지·산불위험·물때·일출일몰·달)

상세 화면의 ‘이번 주말 컨디션’ 카드와 그 수집기 설명입니다. 2026-10-19 처음 만들었습니다.

## 흐름
1. `pipeline/scripts/build-condition-mapping.mjs`는 캠핑장마다 무엇을 볼지 정하는 대응표 `pipeline/registry/condition-mapping.json`을 만듭니다.
   - **기상청 격자**(nx, ny): LCC 변환식으로 로컬에서 계산합니다. 전체 3,116곳이 고유 격자 1,593개에 들어갑니다.
   - **중기육상 구역**: 시도 기준입니다. 강원은 영동(강릉·동해·삼척·속초·고성·양양·태백)과 영서로 나눕니다.
   - **중기기온 도시**: 같은 육상 구역 안에서 가장 가까운 도시를 고릅니다.
   - **에어코리아 측정소**: 40 km 이내에서 고릅니다. 측정소정보 API가 열려 있을 때만 채워집니다.
   - **조석 예보지점**: 25 km 이내에서 고릅니다. 조석예보 API 응답에 있는 위경도로 확인된 지점만 씁니다.
2. `pipeline/scripts/sync-conditions.mjs`는 하루 2회(05:40, 17:40 KST, 워크플로 `Weekend conditions`) 수집해 `camping-atlas/public/conditions/weekend.json`에 씁니다.
3. 화면 `camping-atlas/public/conditions/card.js`는 `design/renewal/app.js`가 동적으로 불러옵니다.
   - **일출·일몰·달**은 `astro.js`로 브라우저가 직접 계산합니다(호출 없음, 서울 하지·동지 기준 ±2분). `astro.js`는 `pipeline/lib/astro.mjs`의 사본이며, 두 파일이 같은지 테스트로 확인합니다.

## 확인이 덜 된 부분 (첫 실제 실행에서 확인)
- 산불위험예보 응답의 필드명은 공개 문서로 확인하지 못했습니다. 수집기는 이름처럼 보이는 칸과 평균 지수처럼 보이는 칸만 골라 남기고, 실제 필드 목록을 `status.fire` 로그에 남깁니다. 등급 구간(낮음 <51, 다소높음 51~65, 높음 66~85, 매우높음 ≥86)은 근사값입니다.
- 조석예보(고·저조)의 요청 경로 `1192136/tideFcstHghLw/GetTideFcstHghLwApiService`는 같은 기관의 시계열 서비스(`tideFcstTime/GetTideFcstTimeApiService`) 경로 규칙을 따랐습니다. 첫 실행에서 404가 나오면 경로만 고치면 됩니다.
- 기상특보는 ‘특보 현황’ 문장에 캠핑장 시군 이름이 들어 있으면 ‘발효 중’으로 표시합니다(구역 경계와 정확히 일치하지는 않음).
