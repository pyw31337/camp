## 아직 겹치는 것(제공 아이콘이 오면 바꿀 자리, #16·#17)
- `users`: 초대 가능 · 방문객 · **놀이터** → 놀이터는 제공 아이콘으로 분리
- `route`: 산책로 · **휴게소·졸음쉼터** → 휴게소는 제공 아이콘으로 분리
- `spark`: **업장(업체) 소개** · **특징·체험** · 폭죽 금지 → 업체 소개·특징체험은 제공 아이콘
- `toilet`: 편의시설 제목 → 제공 ‘편의시설’ 아이콘
- `drop`: 온수 → 제공 ‘온수’ 아이콘
- 관광·맛집·주간 날씨·사이트 타입 제목 → 제공 아이콘
