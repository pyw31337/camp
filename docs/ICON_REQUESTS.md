# 추가 아이콘 요청

현재 상세의 기본 아이콘은 Tabler/Lucide 계열의 24px 라인 아이콘으로 통일되어 있다. 아래 시설은 데이터에 등장하지만 의미가 겹치지 않는 전용 아이콘이 없어 임시로 일반 `시설` 아이콘을 쓴다. 첨부해 주시면 기존 심볼에 같은 방식으로 추가한다.

| 키 | 표시 항목 | 필요한 형태 |
| --- | --- | --- |
| `karaoke` | 노래방 · 노래연습장 | 마이크 또는 노래방 기기, 24×24, `currentColor` 단색 면 아이콘 |
| `garden` | 정원 · 꽃밭 · 수목 공간 | 잎/꽃/정원, 24×24, `currentColor` 단색 면 아이콘 |
| `seminar` | 세미나실 · 회의실 · 강당 | 발표 스크린+사람 또는 회의 테이블, 24×24, `currentColor` 단색 면 아이콘 |
| `stage` | 야외무대 · 공연장 | 무대/스포트라이트, 24×24, `currentColor` 단색 면 아이콘 |

SVG는 `viewBox="0 0 24 24"`와 `fill="currentColor"`를 유지해 주시면 브랜드 색과 접근성 상태가 자동 적용된다.
