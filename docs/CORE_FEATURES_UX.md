# 핵심 기능 선정과 무학습 UX 설계

> 작성일: 2026-10-12 KST · 적용 시안: `design/mockup-v2/` (v2)<br>
> 전제: 로그인 없이 시작하고, 운영비는 무료 범위에서 해결한다([아키텍처](./ARCHITECTURE.md)).

## 1. 핵심 기능 3가지

[데이터→UX 조사](./RESEARCH_DATA_TO_UX.md)의 베네핏 4개를 사용자가 실제로 하는 행동 3개로 묶었다. 화면, 내비게이션, 버튼 문구가 모두 이 세 동사를 따른다.

| # | 사용자 행동 | 기능 | 왜 핵심인가 | 로그인 없이 가능한가 |
| --- | --- | --- | --- | --- |
| 1 | **놓치지 않기** | 예약 오픈 캘린더 + 캘린더 구독 알림 | 인기 캠핑장은 오픈 순간에 마감된다. 일정이 제각각이라 사용자가 가장 많이 헤매는 부분 | 가능. 관심 목록은 브라우저에 저장하고, 알림은 `.ics` 구독으로 사용자 캘린더 앱(구글·애플·삼성·네이버)이 보낸다 |
| 2 | **맞는 곳 찾기** | 날짜·지역·인원·**내 장비** 조건 검색, 상품 유형 7종, 사이트 규격 적합 표시 | 같은 캠핑장도 구역마다 크기·바닥이 달라 텐트가 안 들어가는 일이 잦다 | 가능. 정적 데이터 검색 |
| 3 | **바로 예약하기** | 캠핑장 상세의 예약 가이드(어디서·어떤 방식·미리 할 일·다음 오픈)와 사이트 맵 | 예약처가 흩어져 있어 ‘어디서 어떻게’를 찾는 데 시간이 든다 | 가능. 공식 예약처로 이동 |

보조 기능(핵심 화면의 한 블록으로만 노출): 주말 날씨·바람·일몰, 이동시간·통행료, 최근 현장 링크, 정보 출처.

이번 단계에서 뺀 것: 회원가입, 리뷰 작성, 결제, 실시간 잔여 자리(제휴 전까지 ‘공식 예약처에서 확인’으로 표시).

## 2. 학습 없이 쓰게 만드는 원칙

| 원칙 | 적용 |
| --- | --- |
| **이미 아는 패턴만 쓴다** | 숙박 앱과 같은 검색 바(장소·날짜·인원), 하트=관심, 하단 탭 4개, 바텀시트 필터, 범위 선택 달력, 인원 스테퍼. 새로 배워야 하는 제스처·아이콘 단독 버튼을 쓰지 않는다 |
| **첫 화면에서 두 핵심 기능을 고르게 한다** | 히어로 검색창 위에 탭 두 개: `캠핑장 찾기` / `예약 오픈 일정`. 사용자가 무엇을 할 수 있는지 탭 이름이 바로 알려 준다 |
| **기본값을 채워 둔다** | 날짜는 ‘이번 주말’, 인원은 ‘성인 2’, 장비는 ‘선택 안 함’. 빈 입력 없이도 검색 결과가 나온다 |
| **상태는 아이콘 + 단어 + D-day로** | 색에 의존하지 않는다. `선착순`(번개 아이콘), `추첨`(티켓 아이콘), `상시`(새로고침 아이콘), `D-3`. 주황색은 ‘곧 열림’ 한 가지 의미로만 쓴다 |
| **한 화면에 주 행동 하나** | 홈=검색, 결과=카드 선택, 상세=`알림 받기`/`공식 예약처` 두 버튼(보조·주 버튼 구분), 캘린더=`캘린더에 구독` |
| **결과를 먼저, 설명은 나중** | ‘서비스 소개’ 섹션을 없애고 실제 데이터 카드로 가치를 보여 준다. 신뢰 등급 설명은 배지를 누르면 열린다 |
| **모르는 값은 모른다고 쓴다** | 요금 미연동 → “공식 예약처에서 확인”, 확인 덜 된 일정 → `확인 필요` 배지. 추정 숫자를 넣지 않는다 |
| **되돌리기 쉬움** | 필터 칩은 다시 누르면 해제, 필터 수 배지와 `초기화`, 관심 해제 토스트 |

## 3. 화면별 설계

### 홈
1. 히어로: 사진 위 둥근 패널. 검색 카드 상단에 탭 2개(찾기/오픈 일정). 찾기 탭은 지역·날짜·인원·내 장비, 오픈 일정 탭은 예약처·캠핑장 이름 검색.
2. 캠핑 형태 칩(아이콘 포함): 오토캠핑·캠핑·타프존·쉘터존·카라반·글램핑·캠프닉. 누르면 결과 화면으로 바로 이동.
3. **이번 주 열리는 예약**: D-day 카드 가로 스크롤. 카드마다 종 버튼(관심 추가).
4. **이번 주말 갈 만한 곳**: 사진 카드 그리드. 카드 하단에 다음 오픈 D-day와 예약 방식.
5. 예약처 바로가기: 숲나들e·국립공원·서울 공공예약 등 공통 예약처를 묶어 규칙 요약.

### 찾기(결과)
- 상단: 조건 요약 알약 3개(지역·날짜·인원) + `필터 n` 버튼.
- 지도 띠: 핀에 가격 대신 **다음 오픈 D-day** 또는 `상시`를 표시(레퍼런스 4의 가격 태그 핀을 변형).
- 카드 그리드(PC 3열 → 태블릿 2열 → 모바일 1열). 카드: 사진, 하트, 이름·지역, 상품 칩, 장비 적합 줄, 예약처·방식·D-day.

### 상세
- 사진 위 유리 칩: 토요일 날씨, 바람, 내 위치에서 이동시간(레퍼런스 1·2·3의 정보 오버레이).
- 탭: 개요 / 사이트 / 예약 방법 / 주변.
- **사이트 맵**: 구역 핀을 누르면 `A3 · 데크 4.5×5m`와 내 장비 적합 여부 말풍선(레퍼런스 5의 핀 툴팁).
- 우측(모바일은 하단 고정) 예약 카드: 예약처, 방식, 다음 오픈 D-day, 단계 목록, `알림 받기`(보조) + `공식 예약처`(주).

### 오픈 캘린더
- 월 달력(레퍼런스 5의 달력 형태). 일정이 있는 날에 점, 날짜를 누르면 그날 목록.
- `관심 캠핑장 / 전체 예약처` 전환, `캘린더에 구독`(구글·애플 캘린더용 `.ics` 주소 복사).

## 5. 시각 규칙 요약 (v2)

- 색은 4계열만: 초록(브랜드·행동), 숲색(글자·어두운 면), 중립 회색, 주황 한 가지(‘곧 열림’ 강조). 상태 구분은 아이콘과 단어로 한다.
- 글꼴: Pretendard 하나. 숫자는 `tabular-nums`.
- 아이콘: Lucide(기본 UI)와 Tabler(캠핑·시설 등 Lucide에 없는 아이콘). 스트로크 1.75로 통일.
- 피한 패턴: 그라데이션 글자, 이모지, 01/02 번호 장식, 색 원 안 아이콘 3단 소개, 모든 카드에 같은 그림자, 보라-파랑 그라데이션.
