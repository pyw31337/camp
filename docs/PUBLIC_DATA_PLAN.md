# 공공데이터(캠핑·편의점) 수집·활용 기획 (2026-10-16)

> 2026-10-22 추가: 전국휴양림표준데이터·공공시설 보강 경로로 `k-data.aljal.kr` 공개 색인을 사용한다. 자연휴양림·휴게소·실내놀이터·수영장·레포츠·박물관은 `pipeline/scripts/sync-kdata-public.mjs`가 사이트맵과 상세 페이지에서 좌표·주소·운영 표·원문 링크만 누적하며, 원문 링크가 없는 값은 확정 사실로 표시하지 않는다. 캠핑장 주변 계산에는 `nearby.public` 범주로 최대 3곳씩 연결한다. 공식 원문(숲나들e·도로공사·지자체·공공데이터포털)이 확인되면 더 높은 신뢰 등급으로 병합한다.

> 대상: 소유자가 지정한 data.go.kr 데이터셋·검색 결과(키워드 `캠핑`, `편의점` × 파일·API·표준·연계).<br>
> 목록 원장: `pipeline/registry/public-datasets.json` (88개, 데이터셋마다 활용처·우선순위·채울 속성).<br>
> 모든 에이전트(Claude·Codex·Gemini) 공통 기준. 데이터는 사실 저장소(`docs/FACT_STORE.md`)로 들어가고, 화면은 거기서 읽는다.

## 2. 활용 기획 — 무엇을 어디에 쓰나

### A. 정확도: “없는 곳·닫은 곳·바뀐 곳”을 잡는다 (P0~P1)

- **인허가 3종 대조**: 일반야영장업(API 15155149·파일 15096255), **자동차야영장업(파일 15045088, 신규)**, 관광공사 등록 현황(15037499)을 고캠핑과 주소·좌표(150m)·이름으로 맞춘다.
  - 폐업·휴업 → 카드에 `운영 확인 필요`(사실 `OPERATING_STATUS`에 인허가 원천 추가).
  - 인허가에만 있는 곳 → 숨은 캠핑장 후보(검수 큐).
- **지자체 야영장 현황 36개 파일**(용인·가평·평창·홍천·충남·충북·전북·부산·인천·서울 구별 등): 열 이름이 제각각이다. **공통 정규화기 1개**(열 이름 사전 → 표준 열)로 처리하고 면수·최대 수용 인원·편의시설·안전시설·관리기관을 `CONFIRMED`(기준일 포함) 사실로 넣는다. 고캠핑과 값이 다르면 둘 다 남긴다(조회가 충돌로 표시).
- **농어촌공사·문화정보원·제주 마을캠핑장·국민여가캠핑장**: 고캠핑 누락 후보 발굴용.

### C. 붐빔·예약 경쟁도: 과거 예약·이용 통계 (P2, 차별화)

- 내장산·칠갑산·동강리·당진·구미·화성·문경·여주·망상의 예약·이용자 수 파일 → **월별 붐빔 지수**와 **주말 예약 경쟁도**(공공 캠핑장 한정, 기준 연도 표시).
- 화면: “10월 주말은 예약 경쟁이 높아요(2024년 예약 기준)” 같은 한 줄. 실시간 빈자리로 오해하게 쓰지 않는다(`LIVE_AVAILABLE`과 분리).

### D. 장보기·상비약: 편의점과 주변 생활 인프라 (P0, 체감 가치 큼) — **구현됨(2026-10-16)**

> 실제 구현은 **키가 필요 없는 LOCALDATA 인허가 공개 파일**로 했다(`pipeline/lib/nearby-licensed.mjs`, `scripts/sync-nearby-licensed.mjs`, 주간 워크플로 `public-data-weekly.yml`).
> 업종 7개: 안전상비의약품 판매업소·담배소매인(편의점 체인 상호 판별)·대규모점포·축산물판매업·석유판매업(주유소)·약국·동물병원 → 캠핑장마다 범주별 최근접(직선 m)·5km 안 개수 → `registry/nearby-licensed.json` → 사실 `NEARBY_*_M`(CONFIRMED, 원천 = LOCALDATA 업종 페이지).
> 상가(상권)정보 API(15012005)는 철물점·캠핑용품점처럼 인허가가 없는 업종을 보강할 때 쓴다(다음 단계). 상비약 조회서비스(15154791)는 같은 원천이라 파일로 대신한다.

현재 주변 정보는 OSM이라 시골 편의점·정육점이 비어 있는 곳이 많다.

| 원천 | 얻는 값 | 사실·화면 |

| [소상공인 상가(상권)정보 파일 15083033](https://www.data.go.kr/data/15083033/fileData.do) / API 15012005 | 전국 영업 상가의 상호·업종 소분류·주소·**위경도** | 캠핑장별 최근접 **편의점·슈퍼/농협하나로·정육점·철물점(장작·가스)·낚시/캠핑용품·주유소** 거리 → 새 속성 `NEARBY_*_M`, 카드 “편의점 1.2km” |

- 기준: 직선거리가 아니라 **차로 몇 분**으로 보이려면 카카오모빌리티 길찾기(무료 한도)로 가까운 1곳만 계산한다.
- 상가정보에는 영업시간이 없다. “24시간”은 상비약 판매업소(법상 24시간 운영 요건)일 때만 표시한다.

### E. 사진: 포토코리아로 히어로·지역·테마 (P0, Codex와 협업)

- 관광사진 API로 시군구·키워드(캠핑·계곡·바다·단풍·눈꽃 등)별 사진을 고르고 **웹용 URL + 제목·촬영자·촬영일**을 저장한다(공공누리 1유형: 출처 표시 필수).
- 쓰는 곳: 홈 히어로(실사 요구 충족), 테마 컬렉션 표지, 지역 페이지, 캠핑장 상세의 “주변 풍경”(**그 캠핑장 사진이 아님**을 캡션으로 구분).
- 캠핑장 썸네일은 계속 해당 업장 실제 사진(고캠핑 공식)만 쓴다.

## 5. 지킬 것

- 모든 값은 원천 URL(데이터셋 페이지)·기준일·등급과 함께 사실 저장소로 넣는다(AGENTS.md 3번).
- 오래된 기준일(예: 2020년)은 값 옆에 기준 연도를 보인다. 최신 원천과 충돌하면 둘 다 남긴다.
- 공공누리 사진은 출처(촬영자·한국관광공사)를 화면에 표시한다. 1유형 외 유형(변경 금지·상업 금지)은 따로 표시한다.
- 과거 예약 통계는 “붐빔 경향”으로만 쓰고 빈자리·예약 가능으로 표시하지 않는다.
