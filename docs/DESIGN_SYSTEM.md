# 모여라 캠핑 디자인 시스템

> 최종 갱신: 2026-10-13 KST<br>
> 적용 범위: 검색·결과·상세·여행 계획 화면

## 조사에서 채택한 원칙

여행 예약 화면은 영감용 사진보다 먼저 **여행 조건과 확정 가능성**을 이해시켜야 한다. 에어비앤비의 사례는 하나의 핵심 흐름, 읽기 쉬운 문장 중심 정보 계층, 저장·예약 같은 명확한 행동을 강조한다. Booking.com의 개발 문서는 위치·날짜·인원과 필터를 분리해 실시간 재고·가격을 조회하는 검색 구조를 보여 준다. Google의 반응형 가이드는 화면 폭이 바뀔 때 단순 축소 대신 탐색·필터 컨테이너의 형태를 바꾸도록 권한다.

캠핑 AR·예약 UI 레퍼런스는 몰입감 있는 실제 사진, 부드러운 큰 모서리, 작은 정보 배지, 사진과 일정의 분리된 계층을 보여 준다. 클로드 시안 v2는 그중에서도 **예약 오픈을 첫 번째 콘텐츠로 두고, 검색을 한 장의 큰 히어로 카드 안에 넣으며, 모바일에서 가로 카드와 하단 탐색을 쓰는 구조**가 서비스 목적에 잘 맞았다. 모여라 캠핑은 이 정보 구조를 채택하되, AR·3D 장면처럼 실제 데이터로 뒷받침하지 못하는 효과와 콘셉트 이미지는 넣지 않는다. 대신 공식 사진의 원문, 확인일, 예약의 확정 경계를 같은 화면에서 보여 준다.

그래서 모여라 캠핑은 다음 순서를 고정한다.

1. 첫 화면에서 `캠핑장/예약 오픈`을 고르고 지역·날짜·인원을 입력한다.
2. 검색 바로 다음에 검증 상태와 확인일이 있는 예약 오픈 카드를 둔다.
3. 실제 캠핑장 카드는 사진·형태·규격·정원·공식 예약 안내만 짧게 보여 준다.
4. 상세에서 상품별 재고·요금·정책을 보여 주고, 날씨·경로·주변 여행은 보조 판단 정보로 분리한다.

## 시각 토큰

| 역할 | 값 | 사용처 |
| --- | --- | --- |
| Forest 900 | `#123B2B` | 제목, 로고, 어두운 섹션 |
| Forest 600 | `#287A58` | 주 행동 버튼, 선택 상태 |
| Forest 700 | `#15533C` | 버튼 호버, 강조 |
| Mist | `#FBFCF8` | 기본 배경 |
| Leaf line | `#D8E3D9` | 구분선, 비활성 테두리 |
| Clay | `#BA5B3F` | 보조 링크·주의가 필요한 포인트 |

본문은 따뜻한 백색 배경 위 짙은 녹색을 쓴다. 현재 구현의 Forest는 `#113B2A`, 주 행동은 `#078A50`, 선택 상태는 밝은 민트, D-day와 재확인 필요 상태는 테라코타 `#C85E36`을 쓴다. 초록색은 행동과 정보 신뢰도를 표현하는 데만 사용하고, 예약 불가·추첨·확인 필요는 상태별 배지로 구분한다.

## 이미지 원칙

- 실제 캠핑장 카드: 운영자·공식·계약된 공급자 이미지와 권리·확인일을 함께 표시한다.
- GitHub Pages 파일럿: 운영자 공식 홈페이지가 제공하는 실제 시설 사진을 외부 원문으로 표시하고, 카드마다 원문 링크·운영자·확인일을 표시한다. 원본 파일은 저장하지 않는다.
- 이미지 카드: 16:9 비율, `object-fit: cover`, 고정된 정원·가격 정보와 시각적으로 분리된 메타데이터를 쓴다.
- 접근성: 대표 이미지는 대체텍스트를 제공하고, 장식용 카드는 빈 대체텍스트를 사용한다.
- 현재 화면: 히어로와 상품 카드에는 자라섬캠핑장 운영기관의 시설 안내 원문 이미지만 사용한다. 소셜·후기 사진은 API/임베드 권한, 게시 시각, 캠핑장 매칭이 확인되기 전에는 카드 썸네일로 쓰지 않는다.

## 반응형 규칙

| 범위 | 레이아웃 |
| --- | --- |
| 1021px 이상 | 큰 히어로 검색, 예약 오픈 3열, 실제 상품 4열 |
| 681–1020px | 검색은 3열, 예약 오픈·상품은 2열, 예약처 규칙은 한 줄 카드 |
| 361–680px | 검색 조건을 2열로 재배치, 예약 오픈·실제 상품은 가로 스크롤 카드, 하단 탐색 표시 |
| 320–360px | 좌우 여백 12px, 브랜드 축소, 검색 버튼 전체 폭, 카드 폭은 화면의 86–88%, 가로 넘침 없음 |

320px 기준으로 페이지의 최소 폭을 보장하고, 고정 폭·긴 버튼·불필요한 강제 줄바꿈을 피한다. 단어가 길어진 표 셀은 줄바꿈을 허용하되 화면 밖으로 넘치지 않게 한다.
