# 데이터 → 사용자 가치 조사

> 조사일: 2026-10-12 KST<br>
> 목적: 디자인 시안 전에 **어디서 어떤 데이터를 얻을 수 있고, 그것으로 사용자에게 무엇을 보여 줄 수 있는지**를 정리하고, 서비스의 핵심 가치(베네핏)를 정한다.<br>
> 연결 문서: [기획·설계](./캠핑장_통합검색_예약_서비스_기획_설계.md), [미디어·지도·투어 연동](./캠핑장_미디어_지도_투어_연동_설계.md), [아키텍처 제안](./ARCHITECTURE.md)

## 1. 사용자가 실제로 겪는 문제

캠핑 예약은 숙소 예약보다 훨씬 파편화돼 있다. 조사 중 확인한 사실들이 그대로 사용자 고통이다.

| 문제 | 근거 | 사용자가 하는 일 |
| --- | --- | --- |
| **예약이 언제 열리는지 모른다** | 국립공원 야영장은 성수기만 추첨하다가 시기와 관계없이 추첨으로 바뀌었고(이용월 2개월 전 1~5일 오전 접수, 5일 오후 발표, 취소분은 실시간 선착순) [위키트리](https://www.wikitree.co.kr/articles/938990), [쿠키뉴스](https://www.kukinews.com/article/view/kuk202607100055). 숲나들e 국립휴양림은 비수기 주중 “6주 전 수요일 09:00 선착순”, 주말·성수기 추첨, 미결제분 재오픈이 따로 있다. 민간은 “매월 1일 10시”, “2주 전”, “D-30” 등 제각각이다. | 캠핑장마다 공지·카페·블로그를 찾아 달력에 직접 적는다. |
| **같은 정보가 출처마다 다르다** | 국립공원 추첨 대상 야영장 수를 기사마다 44곳·47곳으로 다르게 보도했고, 블로그는 “짝수 달 접수” 등 공식 자료에 없는 일정을 쓴다. | 어느 정보가 맞는지 판단할 수 없어 결국 공식 사이트를 다시 연다. |
| **예약처가 흩어져 있다** | 숲나들e, 국립공원 예약시스템(카카오 예약·올원뱅크에서도 신청 가능 [데일리안](https://www.dailian.co.kr/news/view/1656210/)), 서울시 공공서비스예약, 시·군 예약 사이트, 캠핏·땡큐캠핑·캠핑톡·야놀자·여기어때, 네이버 예약, 전화·계좌이체 | 앱 5~6개를 설치하고 각각 가입·본인인증을 한다. |
| **“어떤 자리인지”를 비교할 수 없다** | 고캠핑은 사이트 크기(가로×세로×면수)와 바닥 유형을 제공하지만, 플랫폼 상세는 사진 위주라 텐트 크기와 맞는지 알기 어렵다. 공정위·소비자원도 2024년 5개 플랫폼 실태조사에서 사진과 실제가 다른 문제를 지적했다 [SBS Biz](https://biz.sbs.co.kr/amp/article/20000198766). | 리뷰 사진을 확대해 보며 추측한다. |
| **가 보기 전 현장 감이 없다** | 날씨·미세먼지·일몰·물때·최근 현장 사진이 서로 다른 앱에 있다. | 날씨앱·지도앱·인스타를 오가며 확인한다. |

## 2. 데이터 원천 카탈로그와 보여 줄 수 있는 것

## 3. 핵심 베네핏 (디자인이 강조할 것)

조사 결과를 사용자 언어로 압축하면 다음 네 가지다. 시안은 이 순서로 화면 위계를 잡는다.

1. **“언제 열리는지 놓치지 않는다” — 예약 오픈 캘린더 + 알림**
   관심 캠핑장을 담으면 추첨 접수·선착순 오픈·발표·결제 마감·잔여분 재오픈이 하나의 달력에 모인다. 각 일정에는 원문 링크와 확인일, 신뢰 등급이 붙는다. 실시간 재고 없이도 바로 만들 수 있는 가장 큰 가치다.
2. **“내 텐트가 들어가는 자리만” — 사이트 단위 비교**
   텐트·타프 크기와 차량 대수를 넣으면, 고캠핑 사이트 규격(가로×세로)과 바닥 유형으로 맞는 캠핑장·구역만 남긴다. 캠핑·오토캠핑·타프존·쉘터존·카라반·글램핑·캠프닉을 상품 단위로 분류한다.
3. **“예약 방법을 한 장으로” — 예약처·규칙 요약**
   어느 사이트에서, 회원가입·본인인증이 필요한지, 선착순/추첨/전화인지, 시민 감면·우선예약이 있는지 한 카드에 보여 주고 공식 예약처로 바로 보낸다. 숲나들e·국립공원·서울시처럼 공통 규칙은 묶고 시설별 예외는 따로 표시한다.
4. **“가기 전에 현장을 미리” — 주말 컨디션**
   예보·바람·미세먼지·일몰·물때, 내 위치 기준 이동시간과 통행료, 최근 공식 영상을 상세 상단에 요약한다.

이 네 가지를 관통하는 신뢰 장치는 **출처·확인시각·신뢰 등급 배지**다. 경쟁 플랫폼과 블로그가 주지 못하는 “이 정보가 맞는가”를 시각적으로 답한다.

## 5. 하지 않는 것

- 로그인·CAPTCHA를 우회하거나 예약 화면을 자동 조작해 재고를 긁지 않는다.
- 블로그·SNS에 적힌 예약 일정을 확정값으로 쓰지 않는다. 이런 정보는 `E` 등급 제보로만 받아 공식 원문을 찾는 작업을 만든다.
- 다른 캠핑장 사진이나 생성 이미지를 실제 시설 사진처럼 쓰지 않는다. 시안의 이미지는 콘셉트 이미지로 표시한다.
