# Vision 01 — 실제 예약 판단을 위한 탐색 경험

> 상태: 제안·시안 구현 중 (2026-10-16)
> 범위: 현재 `/explore/`를 교체하지 않는 독립 시안 `/vision/`

## 문제 정의

캠핏·땡큐캠핑 같은 예약 채널은 자사 또는 제휴 캠핑장의 거래 전환에 강점이 있다. 모여라캠핑이 이들과 같은 방식으로 보이는 것은 불가능하고 바람직하지도 않다. 전국 시설을 찾아본 사용자가 실제로 겪는 문제는 **다른 운영자·다른 예약처·다른 상품 단위로 흩어진 정보를 같은 질문에 답하게 만들 수 없다는 것**이다.

모여라캠핑은 ‘또 하나의 예약몰’이 아니라 다음을 하는 **캠핑 의사결정 레이어**로 설계한다.

1. 전국 시설을 하나의 탐색 표면에서 찾고, 검증된 공식 예약 채널로 보낸다.
2. 시설 소개가 아니라 사이트·상품·이용 규칙을 같은 읽는 순서로 비교한다.
3. 실시간 잔여, 가격, 접수 중, 후기 언급을 같은 의미로 섞지 않는다.
4. 여행 전 행동(장비 적합성, 길 위 쉼터·마트·화장실)을 예약 결정과 연결한다.

이 역할은 사용자 흐름으로는 네 가지다: **같은 표로 비교 → 관련 콘텐츠를 한곳에서 확인 → 키워드·테마·지도로 탐색 → 내 스펙으로 필터·비교**. 예약은 거래를 복제하지 않고, 실제 등록된 최우선 예약 경로 하나로 빠르게 보낸다.

## 경쟁 서비스와의 역할 분리

| 사용자 질문 | 예약 채널의 본업 | 모여라캠핑의 차별 역할 |
| --- | --- | --- |
| 오늘 내 날짜에 남았나? | 자사/제휴 재고·결제 | 계약·공식 읽기 API가 제공하는 범위만 날짜·인원·상품·수량·TTL을 함께 보여 주고, 미연동 채널은 공식 이동으로 명확히 전환 |
| 내 텐트·전기가 맞나? | 상품 설명마다 제각각 | 전기 W, 사이트 가로×세로, 바닥, 주차, 장작/숯을 동일한 스펙 테이블과 배지로 정규화 |
| 여러 곳 중 어디로 갈까? | 각각의 자기 상품 안에서 비교 | 전국·채널 횡단 지도, 테마, 비교함과 ‘내 장비 조건’으로 후보를 좁힘 |
| 출발할 때 무엇이 필요한가? | 예약 완료 이후 범위 밖 | 주변 마트·공영화장실·휴게소·졸음쉼터·관광지를 이동 맥락으로 묶음 |

## 정보 우선순위

### 카드: 5초 안에 후보를 거르는 정보

1. 큰 공식 사진 최대 5장과 지역·형태 — 카드 안에서 스와이프/드래그, 스크롤바는 보이지 않게 한다.
2. **실시간 상태**: `LIVE_AVAILABLE`일 때만 ‘예약 가능’; 아니면 공식 예약 채널·다음 오픈·확인 필요로 분리
3. 사이트/상품 형태 및 가장 큰 확인된 규격
4. 원문으로 확인된 전기 W, 주차 방식, 장작/숯 규칙만 색상 배지로 표시
5. 세부 출처와 확인 시각은 `i` 버튼에 접고, 신뢰도는 점의 모양·색으로 전달

예약 CTA는 실제 URL이 있을 때만 만들며 **캠핏 → 네이버 예약 → 땡큐캠핑 → 기타 온라인 → 운영자 홈페이지 → 전화** 순으로 하나만 선택한다. 플랫폼의 일반 검색 목록을 대체 경로로 만들지 않는다.

카드의 목적은 빠른 후보 선택이다. 그래서 값이 없거나 후기 언급뿐인 조건은 카드에서 비운다. `확인 필요`는 실패 상태를 과시하는 배지가 아니라 상세의 기본 규격표에서만 작은 회색 텍스트로 쓴다. 후기 언급은 공식 규칙처럼 쓰지 않는다.

### 상세: 설명보다 정규화된 판단 표

상세 화면은 다음 6개 블록을 고정 순서로 갖는다.

1. 공식 사진·이름·지역·예약 상태 요약
2. 날짜/인원별 예약 패널 — 재고 원천이 존재할 때만 수량과 가격
3. 상품·사이트 목록 — 면수, 규격, 바닥, 주차, 인원, 사진
4. 현장 규칙 테이블 — 전기 W, 장작/숯, 반려동물, 입퇴실, 매너타임, 위생, 대여
5. 공식 시설·공지·후기/영상 링크 — API/임베드·저장 약관을 지킨 링크형 연결
6. 가는 길 — 졸음쉼터/휴게소/마트/공영화장실/거리뷰 이동

## 시각 원칙

- **C형 정보 밀도**를 중심으로 쓴다. 표·수치·비교 규칙은 일관되게, 설명문은 짧게.
- **B형 와이드 히어로**: 국내 산지 캠핑의 분위기를 담은 생성 이미지를 배경에 쓰고, 입력 패널이 겹치는 위치는 유리·블러 처리한다. 이 이미지는 특정 업장 사진으로 쓰지 않는다.
- **A형 타이포 대비**: 아주 큰 제목과 작은 모노 라벨을 대조해 한 화면의 우선순위를 즉시 읽게 한다.
- **D형 지도 탐색**: 지도는 장식이 아니라 키워드·테마와 동등한 첫 탐색 모드다. 핀은 신뢰·스펙 충족도에 따라 표현한다.
- 팔레트는 먹색 `#0B0E17`, 코럴 `#FF613E`, 라임 `#A8FF3E`, 블루 `#4D6DFF`로 제한한다. 자연색을 그대로 UI의 저대비 색으로 쓰지 않는다.
- 업장 카드/상세 사진은 고캠핑 등 허용된 공식 원천만 사용한다. 소셜·후기 사진은 원본 저장소로 복제하지 않고, 약관에 맞는 링크·임베드만 쓴다.
- 글은 짧은 명사·값 중심으로 쓴다. `word-break: keep-all`을 쓰지 않으며, 긴 문장으로 학습을 요구하는 대신 탐색 모드·칩·사진 레일 자체가 기능을 설명하게 한다.
- 문서가 유일한 세로 스크롤 소유자다. 가로 탐색이 필요한 사진·칩 레일은 스크롤바를 숨기고 스와이프/드래그와 다음 항목의 노출로만 발견 가능성을 전달한다.

## 데이터 표현 계약

| 필드 | 카드 표현 | 표시 조건 |
| --- | --- | --- |
| 잔여 수량·최종 가격 | 강한 상태/가격 | 시설·상품·날짜·인원·수량/가격·원천 URL·확인 시각·TTL이 모두 있는 공식/계약 데이터 |
| 접수 중 | 보조 상태 | 접수 기간이 열려 있음. 빈자리 의미로 쓰지 않음 |
| 전기 W | `⚡ 600W` 배지 | 운영자 원문 또는 공식 예약/규정에 명시된 값. 후기만 있거나 범위를 모르면 카드에 표시하지 않고 상세 규격표에 회색 `확인 필요` |
| 주차 | `사이트 옆`, `외부 주차`, `차박` | 사이트/구역 단위 공식 규정. 시설 전체 추정 금지 |
| 불멍 | `장작`, `숯만`, `지정 화로대` | 화기 규정 원문. 장작 판매와 불멍 가능을 분리 |
| 사진 | 큰 이미지 | 공식 운영자/공공 제공물 또는 사용 조건을 충족한 매체. 출처는 i 패널 |
| 외부 후기·영상 | 정확도순/최신순 링크·허용 임베드 | 게시 URL·게시일·수집일·매칭 점수·표시 권한이 있는 항목만. 미연동 플랫폼은 검색 링크만 |

## 구현 순서

1. `/vision/`으로 카드·지도·비교 시안의 사용성 검증 — 현재 단계
2. 탐색 인덱스를 작게 발행하고(이름·지역·유형·규격 요약·검증 예약 링크), 시설 상세는 지연 로드
3. 사이트/상품 스키마에 `source_url`, `checked_at`, `confidence`, `scope`을 의무화하고, 전기·주차·불멍부터 원문 추출 우선순위를 둠
4. 공식 또는 계약 재고 피드 1개를 수직 연동해 `LIVE_AVAILABLE`의 날짜·인원·상품 흐름을 완성
5. 제휴/권한 없이 민간 플랫폼의 가격·재고·상품 사진·후기를 자동 수집하지 않음. 예약 이동과 공식 운영자 자료 연결로 시작하고 협력 API 범위를 확장
