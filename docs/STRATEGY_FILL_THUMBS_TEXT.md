# 썸네일·텍스트 데이터 채우기 전략 (2026-10-30, Claude)

소유자 요청: “부족한 썸네일과 텍스트 데이터를 어떻게 채울지 고민하고 전략을 기획해줘.”

## 2. 원칙(바꾸지 않는 것)

1. **허용된 경로만 쓴다.** 공식 API·공공데이터, robots.txt가 허용한 페이지, 봇 이름 공개만 쓴다. 로그인 벽·CAPTCHA·차단 우회는 하지 않는다. 무료 한도 안에서만 돈다.
2. **근거 없는 값은 넣지 않는다.** 모든 값에 원문 URL·인용·확인일을 붙인다. 등급(공식·운영자·플랫폼·후기 언급)은 사실 저장소 규칙을 따른다.
3. **채우기만 한다.** 기존 값을 지우지 않는다. 엇갈리면 검토 대기열로 보낸다(DATA_MERGE_POLICY).
4. **사진은 내용 판정을 거친다.** CLIP 판정과 이름 대조를 거친다. 음식·인물·글 캡처·다른 업장 사진은 대표 사진으로 쓰지 않는다.
5. **우선순위는 정보량 점수(c.iq)를 따른다.** 찜한 곳 → 정보량 낮은 곳 → 많이 보는 곳 순이다.

### 4단계 — 정합성 유지(상시)

- 채운 값은 사실 저장소를 거친다. 다른 원천과 엇갈리면 검토 대기열(현재 849건, 대부분 ‘글램핑·카라반 내부시설’ 423건)로 간다.
  - 에이전트가 원문 대조 후 `quality-decide.mjs`로 판정한다. 하루 50건씩 처리하면 2~3주 안에 상한(200건) 아래로 내려간다.
- 수집 현황판의 자동 진단이 매일 목표 미달·멈춘 수집처·감소를 보여 준다. 주 1회 이 문서의 기대 효과와 실제 숫자를 비교해 다음 순서를 바꾼다.

## 4. 소유자 결정이 필요한 것

1. **사진 저장 방식(P1)**: ⓐ 재압축(바로 가능, 화질 약간 낮아짐) / ⓑ 사진 전용 저장소 + jsDelivr(무료, 저장소 하나 추가) / ⓒ Cloudflare R2(무료 10GB, 계정·키 필요). 추천: **ⓐ로 바로 공간을 만들고, 장기적으로 ⓑ**.
2. **플랫폼 전화번호 표기(X1)**: 카카오·네이버 플레이스에서 온 전화번호를 “플랫폼 등록 번호”로 표기해 쓴다.
3. **로컬 AI 추출(O3)**: 맥미니에서 무료 로컬 모델로 문장 → 구조화를 시험해 볼지. 인용 원문이 있는 것만 채택하는 조건이다.
