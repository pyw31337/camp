# 상세 글 점검 (text review)

상세 화면(`/explore/c/{id}/`)에 나오는 글이 **이 캠핑장 이야기인지**, **그 칸에 맞는지**를 규칙과 이름 맞춤으로 점검합니다. 언어 모델은 쓰지 않습니다. 남긴 글은 원문 문장을 그대로 두고, 시각(14:00)과 금액(130,000원) 표기만 고칩니다. 고치기 전 문장은 `orig`에 남깁니다.

- 규칙: `pipeline/lib/detail-text-review.mjs`. 화면 사본은 `camping-atlas/public/context/text-review.js`이고, 두 파일이 같은지 테스트가 확인합니다.
- 적용 시점: `build-explore-data.mjs`가 `camps/{id}.json`을 쓰기 전에 적용합니다. 화면도 같은 규칙을 다시 적용합니다(결과는 같습니다). 그래서 다음 데이터 갱신을 기다리지 않고 바로 반영됩니다.
- 공통 문구 목록: `public/context/text-common.json`. 시도 3곳 이상, 캠핑장 8곳 이상에 똑같이 붙은 문장(관광 포털·예약 사이트 틀)입니다.
- 세기: `cd pipeline && node scripts/review-detail-texts.mjs`. 결과는 `pipeline/out/text-review.json`에 저장되고, 파일은 바꾸지 않습니다.

## 규칙

| 칸 | 빼는 글 |
|---|---|
| 운영자 안내 | 정보 모음·후기 사이트(캠핑픽·캠핑허브·캠퍼스토리·관광공사 포털 등) 글, 여러 캠핑장 공통 문구, 약관·개인정보, 페이지 제목, FAQ 질문, 항목 이름만 있는 줄, 일반 캠핑 안내, 방문 후기, 다른 업장 이야기, 같은 문장 반복, 운영 정보 항목에 맞지 않는 글 |
| 사이트 타입 | 정보 모음 사이트 페이지 제목에서 뽑은 종류(개수 없음) |
| 요금 언급 | 1박 범위(1만~200만 원) 밖 금액, 여러 캠핑장 모음 글, 다른 업장 문장, 같은 글·같은 금액 반복 |
| 블로그·카페·영상 | 캠핑장 이름이 없는 글, 광고·스팸 |

운영자 안내는 낱말 점수로 항목을 다시 정합니다(`cat`): 입·퇴실 / 예약 · 성수기 / 요금 · 환불 / 인원 · 추가 / 주차 / 전기 / 불멍 · 화로 / 반려동물 / 매너타임 · 소음 / 시설 / 이용 규칙 / 사이트 이용.
