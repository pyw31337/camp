# 추가 아이콘 요청

현재 Tabler/Lucide 묶음에 의미가 충분히 구분되는 면 아이콘이 없어, 아래 네 항목은 임시로 일반 시설 아이콘을 쓰지 않고 보류한다.

| 키 | 용도 | 요청 형태 |
| --- | --- | --- |
| `karaoke` | 노래방 | 24×24, `currentColor`, 면 아이콘 |
| `garden` | 정원·산책정원 | 24×24, `currentColor`, 면 아이콘 |
| `seminar` | 세미나실·회의실 | 24×24, `currentColor`, 면 아이콘 |
| `stage` | 공연장·무대 | 24×24, `currentColor`, 면 아이콘 |

SVG를 받으면 `design/renewal/index.html`의 심볼 목록에 넣고, 시설명 매핑에만 연결한다.
