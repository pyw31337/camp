# 캠핑장 프로필·한 줄 요약·분류 태그 (2026-10-16)

> 목적: 전국 3,116곳 각각을 **같은 18개 항목**으로 정리해, 다른 플랫폼을 오가지 않고 비교·판단할 수 있게 한다.<br>
> 코드: `pipeline/lib/campground-profile.mjs`, 실행: `pipeline/scripts/build-campground-profiles.mjs`(data-sync 마지막 가공 단계).<br>
> 화면 연결은 디자인 작업자(Codex)가 이 읽기 모델을 가져다 쓴다. 이 문서는 데이터 계약이다.<br>
> 취향·조건 조합(필터·추천)은 이 요약이 아니라 원자 사실 저장소 `data/facts`(`docs/FACT_STORE.md`, 125개 속성)를 쓴다.

## 1. 원천과 등급

| 등급 | 뜻 | 원천 | 요약·태그에 쓰나 |
| --- | --- | --- | --- |
| `VERIFIED` | 사람이 공식 원문과 대조 | `registry/pilot-condition-facts.json`(파일럿) | 예 |
| `OPERATOR` | 운영자가 스스로 공개한 문장에서 자동 추출 | 운영자 홈페이지·예약 페이지(`operator-site-snippets.json`), 운영자 공지 | 예 |
| `CONFIRMED` | 한국관광공사 고캠핑 등록값·공식 소개 | 고캠핑 API | 예 |
| `MENTION` | 후기 언급(건수와 함께) | Daum 블로그·카페 검색 요약 | **아니오**(프로필 칸에 ‘후기 n건’으로만) |

모든 값은 `source = { label, url, date, quote }`를 가진다. 원천이 없는 항목은 만들지 않는다(화면은 ‘확인필요’).

## 2. 18개 항목

| 코드 | 항목 | 우선순위(위가 먼저) |
| --- | --- | --- |
| `TYPE` | 유형·규모(오토 30 · 글램핑 5) | 고캠핑 |
| `CHECKIN` / `CHECKOUT` | 입실 / 퇴실 | 운영자 문장 → 고캠핑 소개 → 후기 언급(2건↑) |
| `MANNER` | 매너타임 | 같음 |
| `PRICE` | 1박 요금(최저~최고) | 운영자 요금 문장 → 후기 언급 요금대 |
| `EXTRA_FEE` | 추가 인원·차량·방문객 | 스펙 시트 |
| `POWER` | 전기(최대 W, 전기 사용료) | 원문 대조 → 운영자 W → 고캠핑 ‘전기 제공(W 미확인)’ |
| `PARKING` | 사이트 옆 / 외부 주차 | 원문 대조 → 운영자 |
| `FIRE` | 장작 가능 / 숯만 / 개인 화기 불가 / 불멍 세트 유료 / 화로대 개별 | 원문 대조 → 운영자 → 고캠핑 화로대 |
| `CAR_CAMPING` | 차박 가능·불가 | 운영자 |
| `PET` | 반려견(크기·요금) | 운영자 문장 → 고캠핑 |
| `SITE` | 사이트 규격·바닥 | 원문 대조 → 고캠핑 |
| `SANITARY` | 화장실·샤워 수, 온수 | 고캠핑 + 운영자 |
| `AMENITIES` | 편의시설(운영 기간 포함, 예: 수영장(7월~8월)) | 고캠핑 + 운영자 |
| `SEASON` | 연중 운영 / 기간 휴장 / 사계절 | 운영자 → 고캠핑 |
| `REFUND` | 취소·환불 규정 있음(원문 문장) | 운영자 |
| `BOOKING` | 예약 채널 | 고캠핑 등록 예약 정보. CTA는 `booking.primary`의 한 경로만 사용(캠핏 → 네이버 → 땡큐캠핑 → 기타 온라인 → 홈페이지 → 전화) |
| `REVIEW` | 후기 장단점 | 후기 요약(`build-review-digest.mjs`) |

## 3. 한 줄 요약

확인된 값(`MENTION` 제외)만 고정 순서로 최대 6조각: **유형·규모 → 입실 → 1박 요금 → 전기 W → 불멍 → 주차 → 차박 → 반려견**.
예: `오토 30·글램핑 5 · 입실 14:00 · 1박 4만~5만원 · 전기 600W · 장작 가능 · 반려견 가능(소형견)`

## 4. 분류 태그(근거 포함)

| 묶음 | 태그 | 근거 |
| --- | --- | --- |
| 입지 | 산·숲·계곡·강·호수·바다·섬·도심 근교 | 고캠핑 입지 |
| 형태 | 오토캠핑·글램핑·카라반 | 고캠핑 유형 |
| 상황 | 가족·키즈, 반려견 동반, 차박, 겨울 운영, 물놀이 | 부대시설·운영자 문장·고캠핑 |
| 조건 | 장작 불멍, 사이트 옆 주차, 고전력(1kW↑) | 원문 대조·운영자 문장만 |
| 후기 | 후기: 조용 / 경치 / 깨끗 / 친절 | 후기 2건 이상, ‘후기’ 접두로 사실과 구분 |

## 5. 출력(읽기 모델)

- `camps/{id}.json` → `profile = { version, generated_at, fields{코드: {value, grade, source, …}}, tags[{code,label,why}], summary, score{known, facts, total} }`
- `campgrounds.json` → `pf = { s: 요약, t: [태그 코드], k: 확인 항목 수 }` (목록·필터용, 가볍게)
- `meta.json` → `profiles = { fields{코드:{any, facts}}, tags{코드:수}, facts_distribution }`

예약 채널 원본은 `booking.channels`에 남기고, 공개 화면의 단일 예약 행동은 `booking.primary`만 읽는다. 이 선택은 예약 가능·가격·상품 정보를 의미하지 않으며, URL·원천·확인 시각은 기존 채널 근거를 따른다.

## 6. 하지 않는 것

- 네이버·캠핏·땡큐캠핑·야놀자 등 플랫폼 페이지 자동 수집(약관). 평점은 원천이 없어 만들지 않는다(`PROJECT_PLAN.md` 결정 대기).
- 후기 언급을 확정값·요약·조건 태그로 올리기.
- 모르는 칸을 기본값(600W, 지정 주차 등)으로 채우기.
