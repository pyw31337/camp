## 2. 모든 에이전트 필독 수집 및 개발 규칙

1. **유료 결제 수단 연동 금지**:
   - 어떠한 외부 서비스나 API도 신용카드나 유료 결제 프로필을 등록하여 사용하는 것을 엄격히 금지합니다.
2. **사전 무료 검증 (Fail-Closed) 준수**:
   - 네이버 등 조건부 한시 무료 API는 호출 전 반드시 `naver-guard.mjs`의 `checkFreeTier()` 검증을 거쳐야 합니다. 페이지 접근 실패나 0원 외 금액 표기 발견 시 절대 호출하지 않고 즉시 작업을 중단합니다.
3. **하드 캡(Hard Cap) 상한 준수**:
   - 카카오 Daum 검색 등 일일 무료 쿼터가 존재하는 API를 호출할 때는 `SOCIAL_MAX_CALLS=9100`과 같이 일일 무료 한도(20,000건)의 절반 이하로 안전 버퍼를 유지합니다.
4. **Supabase DB 용량 관리**:
   - 데이터 적재 시 대용량 바이너리(이미지, 원본 동영상 파일 등)는 DB에 BLOB/BYTEA 형태로 저장하지 않고, 텍스트 메타데이터 및 원천 URL만 보관합니다.
   - 주기적으로 `npm --prefix pipeline run check:billing`을 실행하여 현재 500MB 중 사용 용량을 모니터링합니다.

## 3. 원클릭 무과금 안전 점검 실행법

에이전트나 작업자는 터미널에서 다음 명령어로 모든 외부 서비스의 무과금 안전성을 1초 만에 점검할 수 있습니다:

```bash
npm --prefix pipeline run check:billing
```

GitHub Actions 상에서는 `.github/workflows/api-key-check.yml` 워크플로를 수동 실행하거나 push하여 통합 점검할 수 있습니다.
