# 품질 전수 점검 기록 — 2026-10-22

## 데이터 정합성

- 구조화된 전력 제한값 `limit_w`/`regulatory_reference_w`를 전수 검사한 결과 400W 미만은 0건이다.
- 1박 요금 하한 검사를 다시 적용했다. 민간 1박 2만원 미만은 `fee_raw`에 원본을 보존하고, 대체 근거가 없으면 표시 요금에서 숨겼다.
- 이번 적용은 65건이며, 적용 후 표시되는 2만원 미만 값은 국·공립 공식요금 또는 캠크닉·당일 이용 예외 6건뿐이다.
- 요금 표시 필드와 사이트·요금 행의 레이블을 검사한 결과 환불·취소·대기·결제 문장이 숙박 요금 레이블로 들어간 항목은 0건이다. 후기 원문 인용은 근거 팝오버에만 남긴다.
- 표시 텍스트의 HTML 엔티티(`&quot;`, `&lt;`, `&amp;`, `&middot;` 등)를 정제 함수에서 복원하고, URL 필드는 보존하도록 수정했다.

## 브라우저 점검

- 파이프라인 회귀: 가격·라벨·운영문구·조건·상세 텍스트 관련 테스트는 통과했다.
- 전체 Node 테스트는 119개 중 118개 통과했다. `photo-dedupe.test.mjs`는 로컬에 `sharp` 패키지가 없어 실행되지 않았다.
- PC·모바일·태블릿 스크린샷 회귀는 로컬에 `playwright` 패키지가 없어 실행되지 않았다. 따라서 Safari·삼성 브라우저·웨일·Chrome·Firefox별 실제 캡처 검증은 아직 완료되지 않았다. CI 또는 Playwright 의존성 설치 후 동일 스크립트를 재실행해야 한다.

## 남은 리스크

1. 2만원 미만 요금 6건은 공개 공식요금/당일 이용 예외로 남겼지만, 화면에는 이용 형태와 근거 등급을 함께 보여야 한다.
2. 브라우저별 실제 스크린샷과 320px 가로 넘침 검사는 Playwright 환경 복구 후 완료해야 한다.
3. 사진 중복 검사(`sharp`) 실패는 환경 의존성 문제로, 데이터 손실로 판단하지 않고 설치 후 재검증한다.
