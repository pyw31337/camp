# 탐색 경험 확장 계획

> 작성: 2026-10-13 KST
> 목표: 사용자가 별도 검색을 반복하지 않고 전국 캠핑장·글램핑·카라반을 비교하고, **확인 가능한 공식 경로**로 예약을 이어 갈 수 있게 한다.

## 이번 구현 범위

1. 예약 CTA를 ‘예약하기’ 단일 버튼에서 **공식 예약 링크 / 공식 홈페이지 / 고캠핑 시설 안내 / 전화 문의**로 분리하고, 원천·확인 시각·신뢰도를 표시한다.
2. 고캠핑의 사이트 형태·면수와 TourAPI의 상품 단위 가격·사진을 분리해 시각 카드로 제공한다. TourAPI 상품이 없을 때는 만들어 내지 않고 해당 상태와 공식 안내 링크를 보인다.
3. 시설 공식 홈페이지·고캠핑·TourAPI 원문을 한 모듈로 묶고, 운영자 소개와 혼동하지 않게 표시한다.
4. 주변 POI를 사진 카드(원천 사진이 있는 경우)와 지도/길찾기/카카오 로드뷰 동작으로 강화한다. 카카오 로드뷰는 좌표 주변 파노라마가 있을 때만 표시한다.
5. 저작권·플랫폼 경계를 지킨 후기/영상 갤러리를 강화한다. Daum 검색 결과는 썸네일 URL과 원문 링크만, YouTube는 공식 `youtube-nocookie` 임베드만 쓴다. TripAdvisor·TikTok은 API/임베드 승인 전에는 검색 링크만 제공한다.
6. 목록→상세만의 단일 흐름을 컬렉션·예약 가이드·패스포트 같은 별도 정보 페이지로 확장한다. 재미 요소는 ‘탐색·준비 완료’ 배지와 컬렉션으로 제한하고, 금전 결제·예약 성공을 게임화하지 않는다.

## 데이터 보강 운영

- 사진: 수·금에는 사진 없는 시설 우선으로 고캠핑 공식 `imageList`를 수집하고, Pages 용량을 넘지 않도록 대표 1장 우선 정책을 유지한다. 수집 시 URL·확인 시각·권리 근거를 매니페스트에 보관한다.
- 상품/요금: TourAPI 숙박·야영장 등록 상품을 주기적으로 보강한다. 사진은 원본을 재호스팅하지 않고 원문 URL을 사용하며, 가격은 ‘공식 등록 기준가’와 확인 시각으로 한정한다.
- 예약 링크: 매 주기 HTTP 검증 결과를 별도 관측으로 보관해 4xx/리다이렉트가 누적된 링크를 ‘확인 필요’로 낮춘다. 원천이 바뀌면 자동으로 단정하지 않고 공식 홈페이지·전화 대체 경로를 남긴다.
- 주변 정보: 공중화장실·휴게소·졸음쉼터·OSM POI는 좌표·원천·갱신 시각을 유지한다. 상업 POI 사진은 제공 원천에 사진이 있을 때만 표시한다.

## 다음 단계와 수용 기준

1. 예약처별 날짜·인원 입력을 실제로 읽는 어댑터가 계약/허가된 원천으로 추가되기 전에는 빈자리 상태를 `OFFICIAL_CHECK_REQUIRED`로만 노출한다.
2. 공식 시설 사이트가 없는 업장은 고캠핑 원문과 전화만 노출하며, 존재하지 않는 시설 안내/상품을 생성하지 않는다.
3. 각 화면은 모바일에서 사진·영상·카드가 가로로 탐색 가능하고, 모든 외부 이동은 새 탭·원문 표시·안전한 `noopener` 처리를 가진다.
4. 자동 배포 전 파이프라인 단위 테스트, 탐색 번들 구문 검사, Pages 빌드 및 대표 상세 흐름을 확인한다.
