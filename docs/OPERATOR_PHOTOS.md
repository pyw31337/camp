# 운영자 사이트(상품) 사진 올리기

2026-11-11 t62. 사용자 화면 변경은 **camp-preview 테스트 URL만**. 실제 사이트에는 올리지 않는다. 공식 채널 배지(`preview/t61-channels`)와 t54 카드·사진은 나중에 함께 반영하기로 했고, 지금은 그 분기를 합칠 수 있게만 유지한다.

기존 운영자 정정 양식(`docs/OPERATOR_FORM.md`, `operator_submission`) 옆에, 사이트 유형을 고르고 상품 사진을 올리는 칸을 붙인다.

## 사장님인지 어떻게 보나

1. **고캠핑 등록 전화번호로만 OTP.** 화면에 끝 네 자리를 가린 번호만 보이고, 사용자가 다른 번호를 넣을 칸이 없다. 카카오·네이버로 채운 번호(`tel_src`)는 쓰지 않는다. 그 경우에는 문자 인증을 열지 않고 바로 2번으로 간다.
2. **예비: 사업자등록번호.** 국세청 사업자 상태조회 API(`POST https://api.odcloud.kr/api/nts-businessman/v1/status`, data.go.kr)로 계속사업자(`b_stt_cd=01`)인지 본다. 휴업·폐업·미등록은 거절. 상호를 받으면 시설명과 맞춘다(이름 유사도 0.72 이상, 또는 핵심 이름 포함). 계속사업자인데 상호가 잘 안 맞으면 대기열에는 넣되 ‘상호 불일치’로 관리자가 다시 본다. 대표자명·개업일이 있으면 진위확인(`/validate`)도 쓸 수 있다. **serviceKey는 서버에만 둔다.**
3. **올린 사진은 바로 공개하지 않는다.** 검수 대기열로 들어가 자동 판정(파일 형식·크기·비율, 서류·등록증·배치도 필터, 요금표·배너 등 광고성 파일 이름, 운영에서는 `site-photo-classify` CLIP)을 거친 뒤, **관리자가 승인한 것만** 공개한다.

미리보기에서는 OTP를 화면에 보여 주는 흉내만 내고, 국세청도 호출하지 않으며, 대기열은 이 브라우저 `localStorage`에만 둔다. 운영 Supabase에는 쓰지 않는다.

미리보기 시험 사업자번호: 계속 `123-45-67891`, 폐업 `999-00-00001`, 휴업 `888-00-00002`(실제 업체가 아니라 검사 숫자만 맞는 시험 값).

## 운영에 넣을 때(아직 하지 않음)

- 테이블: `db/028_operator_photos.sql` (`operator_photo_submission`, anon은 INSERT·PENDING만).
- 문자·국세청 호출은 **Supabase Edge Function(또는 같은 역할의 서버)** 에서만. 브라우저에 SMS 키·serviceKey를 넣지 않는다.
- 사진 파일은 R2 또는 Supabase Storage. 공개 URL은 승인 뒤에만.
- 관리자 페이지는 기존 운영 대시보드와 같은 인증이 필요하다. 미리보기 검수 페이지는 비밀번호가 없다.
- CLIP 판정은 파이프라인 `site-photo-classify`로 관리자 화면에서 다시 돌린다. 브라우저에서 전체 CLIP을 돌리지 않는다.

## 문자(SMS) 업체와 비용 — 조사만, 가입·결제하지 않음

2026-11 공개 요금 기준(부가세 별도일 수 있음. 적용 전에 해당 업체 페이지에서 다시 확인할 것).

| 업체 | SMS(건) | 카카오 알림톡(건) | 참고 |
| --- | --- | --- | --- |
| 알리고(aligo) | 약 8.4원 | 약 6.5원 | 최저 충전이 보통 5만 원, 월 기본료 없음 |
| 솔라피(Solapi, CoolSMS와 같은 계열) | 웹 발송 약 18원 | 웹 약 13원, API 직접이면 알림톡 약 8원 | 개발 문서·SDK가 잘 되어 있음 |

인증번호는 정보성 알림톡으로 보내는 편이 더 싸다. 알림톡이 실패하면 SMS로 이어 보내는 구성이 흔하다.

초기 규모를 한 달에 인증 200건으로 보면, 알림톡 기준 약 1,300~2,600원, SMS만 쓰면 약 1,700~3,600원 수준이다(부가세 별도).

### 실제 적용 때 소유자가 준비할 것

1. **문자 업체 계정** — 알리고 또는 솔라피 중 하나(추천: 단가면 알리고, 연동 편의면 솔라피). 사업자 회원, 선결제 충전.
2. **발신번호 사전 등록**(전기통신사업법). 캠핑 안내 전화 또는 회사 번호.
3. **알림톡을 쓸 경우** 카카오 비즈니스 채널, 발신 프로필, 인증번호 템플릿 심사.
4. **국세청 상태조회 활용신청** — 이미 있는 data.go.kr 계정·`DATA_GO_KR_SERVICE_KEY`에 ‘국세청_사업자등록정보 진위확인 및 상태조회 서비스’만 추가 신청하면 된다. 호출량 한도는 보통 1회 100건·1일 100만 건, 이용 요금은 없다.
5. **서버 비밀 값** — SMS API 키, 필요하면 국세청 키를 Edge Function 비밀로. 프론트에 넣지 않음.
6. **사진 저장소**(R2 또는 Supabase Storage)와 승인 뒤 공개 경로.
7. **개인정보** — OTP 로그·사업자번호 보관 기간. 전화 원문은 제출 행에 남기지 않는 편이 낫다.
8. 관리자 인증을 검수 페이지에 붙일 시기.

이 목록은 결정·계정만 필요한 항목이다. 이 작업에서는 가입하거나 결제하지 않았다.
