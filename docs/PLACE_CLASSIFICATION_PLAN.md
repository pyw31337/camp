# 업장 유형별 정보 표현 계획

## 목적

민간 캠크닉·캠프닉 업체와 무료 공원은 숙박 캠핑장과 같은 규격·요금 질문으로 비교하면 정보가 빈약해 보이거나 잘못된 의미가 된다. 원장에 있는 사실을 지우지 않고, 유형에 맞는 공통 정보 계약으로 카드와 상세 화면에서 읽히게 한다.

## 분류와 공통 필드

| 유형 | 카드·상세 공통 필드 | 숙박 캠핑장과 다른 점 |
| --- | --- | --- |
| 숙박 캠핑 | 이용 방식, 사이트·규격, 요금, 전기·바닥, 규칙, 예약 | 1박 사이트와 숙박 요금을 우선 |
| 민간 캠크닉 | 당일 이용, 운영 시간, 당일 요금, 시설, 이용 규칙, 예약 | 숙박 요금으로 추정하지 않고 예약 화면 확인을 명시 |
| 무료·공공 공원 | 이용 방식, 시설, 화장실·편의, 관리기관, 이용 규칙 | 요금·사이트 규격이 없으면 만들지 않고 무료·공원 이용으로 표현 |

## 화면 규칙

- 카드에는 유형 배지와 위 공통 필드를 같은 순서로 표시한다.
- 상세에는 `캠크닉 이용 정보` 또는 `공원 이용 정보` 섹션을 별도 노출한다.
- 값이 없거나 원천에서 확인되지 않은 항목은 `확인 필요`로 표시한다. 임의의 운영 시간·요금을 만들지 않는다.
- 원문·확인 시각은 기존 작은 정보 버튼과 출처 링크를 사용한다.
- 320px에서도 값이 잘리지 않도록 행의 라벨 열을 고정하고 값은 자연 줄바꿈한다.

## 데이터 보강 우선순위

1. 민간 캠크닉: 운영 시간, 당일 요금, 예약 URL, 취사·그늘막 규칙, 편의시설.
2. 무료 공원: 관리기관·전화, 화장실 위치, 주차·취사·그늘막 규칙, 시설 목록.
3. 사진은 공식 원천을 우선하고, 후기 사진은 업장 일치 검증을 통과한 경우에만 사용한다.

## 현재 구현

- `design/renewal/app.js`의 `publicParkCard`, `picnicCard`, `classificationProfileHtml`에 유형별 카드·상세 표현을 적용했다.
- 기존 사실과 출처는 유지하며, 화면 문장만 공통 포맷으로 정제한다.
- 다음 수집 작업은 위 우선순위 필드가 비어 있는 업장부터 증분 병합한다.
