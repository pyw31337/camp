# 프로젝트 계획

> 최종 갱신: 2026-10-13 KST<br>
> 제품명: 모여라 캠핑<br>
> 상태: GitHub Pages 공개 파일럿(`camping-atlas/`) + 전국 기준 데이터 파이프라인 구현 · 핵심 기능 3개 확정, 디자인 시안 v2 검토 대기, Cloudflare Pages 미리보기 배포

## 제품 목표

사용자는 날짜·인원·차량·캠핑 형태·현장 조건을 넣고, 전국 공영·민간 캠핑장의 **상품 단위** 가격·규격·예약 방법·실제 예약 가능 상태를 비교한다. 상세 화면에서는 공식 사진과 최신 분위기 콘텐츠, 날씨, 이동·통행료, 인근 여행 정보를 서로 다른 근거로 확인한다.

## 제품 원칙

1. `캠핑장`과 `판매 상품`을 분리한다. 오토 사이트, 타프존, 쉘터존, 글램핑, 카라반, 캠프닉은 별도 상품이다.
2. ‘이번 주말 예약 가능’은 공식 채널의 날짜·인원 조건을 유효 시간 안에 검증한 `LIVE_AVAILABLE`만 포함한다.
3. 수집 시각, 원천 URL, 신뢰도, 만료 시각을 값과 함께 보관한다.
4. 공식 시설 정보, 이용자·소셜 콘텐츠, 추천·검색 결과를 서로 대체하지 않는다.
5. 사진은 사용권이 명시된 공식 자산 또는 플랫폼 임베드로만 노출한다.

## 핵심 베네핏 (2026-10-12 확정 제안)

[데이터→UX 조사](./RESEARCH_DATA_TO_UX.md) 결과, 실시간 재고 없이도 공개 원천으로 바로 제공할 수 있고 사용자 고통이 가장 큰 기능부터 만든다.

1. **예약 오픈 캘린더·알림** — 선착순 오픈, 추첨 접수·발표, 미결제분 재오픈을 관심 캠핑장별로 모은다. 첫 번째 핵심 기능.
2. **사이트 단위 비교** — 내 텐트·타프 크기에 맞는 사이트(가로×세로·바닥)만 남긴다.
3. **예약 방법 한 장 요약** — 예약처, 선착순/추첨/전화, 사전 준비, 감면을 공식 원문 기준으로 정리한다.
4. **주말 컨디션** — 예보·바람·미세먼지·일몰·이동시간·통행료.

## 현 단계의 우선순위

1. GitHub Actions 비밀 저장소의 고캠핑 API 키로 `pipeline`의 동기화를 실행하고, 원본 결과를 공개 카탈로그와 PostgreSQL 적재 작업에 순서대로 연결한다. 키는 저장소에 넣지 않는다.
2. `pipeline`의 PostgreSQL 적재를 시설·상품·규격뿐 아니라 공중화장실, 휴게소·졸음쉼터, 주유 가격 관측, 무료 후보, 예약 규칙/계산 일정까지 외부 식별자 기준으로 재실행 가능하게 연결했다. 운영 `DATABASE_URL`을 비밀 관리 환경에 넣으면 동기화 뒤 마이그레이션과 전체 스냅샷 적재가 실행된다. 상세한 원천·주기·롤백 기준은 `docs/DATA_FOUNDATION_PLAN.md`를 따른다.
3. 숲나들e·국립공원·공유누리·지자체·민간 운영자용 예약 제공자 레지스트리를 실제 원천 URL·오픈 규칙·추첨 규칙으로 확대한다.
4. 첫 번째 읽기 전용 예약 어댑터를 계약 또는 공식 허가 범위에서 구현하고, `LIVE_AVAILABLE`은 날짜·인원별 원천 검증을 거친 값만 반환한다.
5. 파일럿의 자라섬 정적 레코드를 API 응답으로 교체하고, 상품·미디어·공지·예약 제공자 레지스트리를 전국으로 확대한다.
6. 운영자 공식 채널 연결과 네이버·유튜브 검색 어댑터를 구현해, 게시 URL·게시 시각·매칭 근거·표시 권한이 있는 최근 콘텐츠만 상세에 노출한다.
7. `pipeline/out/open-calendar.json`을 정적 파일럿 값이 아닌 배포 시 생성되는 읽기 전용 API 응답으로 연결하고, 일정별 공식 원천과 유효 시각을 유지한다.
8. GitHub Pages 데이터 발행기를 통해 예약 캘린더와 권리 검토를 통과한 고캠핑 발견 레코드를 `camping-atlas/public/data/`로 내보낸다. 공공데이터포털의 고캠핑 API 이용허락범위가 제한 없음으로 표기된 원문을 2026-10-13 KST에 확인했고, `GOCAMPING_CATALOG_PUBLISH_APPROVED=true`일 때 시설 식별값·분류·규격·원천만 공개 카탈로그로 발행한다.

## 수용 기준

- 데이터: 변경된 필드는 원천, 관측 시각, 검증 상태를 조회할 수 있다.
- 데이터 운영: 전량 초기 적재와 원천별 주기 갱신의 실행 이력·해시·수신/수용 건수를 조회할 수 있다.
- 예약: `LIVE_AVAILABLE`, `LIVE_SOLD_OUT`, `OPEN_SCHEDULED`, `LOTTERY_OPEN`, `OFFICIAL_CHECK_REQUIRED`, `STALE`을 혼동 없이 표시한다.
- 가격: 통화, 기준/최대 인원, 추가 인원·차량·옵션, 적용일·요일·시즌·채널을 상품 단위로 저장한다.
- 공간: 사이트 규격은 폭·깊이·면적·바닥·적용 수량·출처를 구분한다.
- 미디어: 모든 카드에 원천과 권리 상태가 있고, 소셜 원문은 임베드·링크 중심으로 표시한다.
- 발행: 공개 정적 카탈로그는 가격·재고·사진 원본을 담지 않고, 기준 시설 식별값·분류·규격·수집 시각·원천만 보존한다.
- 지도/날씨: 현재 위치는 사용자의 명시적 동의가 있어야 쓰며, 원좌표를 불필요하게 장기 보관하지 않는다.
