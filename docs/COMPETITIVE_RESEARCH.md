## 렛츠 캠핑의 우위

- 예약 가능한 일부 업장만 과장하지 않고 전국 카탈로그를 유지한다.
- 사이트 규격·바닥·전력·주차·불멍·이용 제한·요금을 한 형식으로 정규화한다.
- 원문 URL·확인 시각·신뢰 등급을 남겨 값의 범위를 설명한다.
- 후기 사진·행사·주변시설을 자동 판정해 음식 사진, 무관 업체, 원거리 행사를 격리한다.
- 비교·지도·찜을 예약 플랫폼과 독립적인 의사결정 도구로 제공한다.

## 개발 우선순위

### 1. 예약 오픈·빈자리 감시(최우선)

시설·상품·날짜·관측시각·원문 URL이 모두 있는 경우에만 `관측 가능`으로 표시한다. 알림은 캠핑장별로 구독하고, 미지원 업장은 ‘예약처에서 확인’으로 남긴다. 매진과 미연동을 같은 결과로 취급하지 않는다.

### 2. 데이터 신선도와 충돌 설명

상세 핵심값에 `확인일`과 `출처 수`를 작게 표시하고, 서로 다른 값이 있을 때 최신·상위 등급·독립 원천 수를 기준으로 선택한 이유를 원문 팝업에 기록한다. 값이 오래되면 자동으로 ‘재확인 필요’ 상태로 낮춘다.

### 3. 캠핑 적합성 비교

사용자 장비 크기·필요 전력·차량·반려견 조건을 로컬 프로필로 저장하고, 사이트 단위 표에서 `맞음/조건부/확인 필요`를 보여준다. 예약 가능 여부와 적합성은 별도 상태로 유지한다.

### 4. 주변 동선 카드

마트·편의점·약국·병원·휴게소·주유/충전·행사·관광을 거리·영업 정보·로드뷰와 함께 묶어 출발 전/도착 후 동선으로 보여준다. 사진은 공식 또는 판정 통과 자료만 사용한다.

### 5. 운영자 정정 경로

각 사실의 ‘잘못된 정보 신고’를 원문 위치와 함께 접수하고, 병합 정책·품질 장부·검토 큐로 연결한다. 운영자 인증은 추후 선택적으로 도입한다.

## 이번 개발에서 적용할 기준

현재 화면은 위 우선순위 중 2~4번의 데이터 구조와 출처 팝업을 이미 갖추고 있다. 다음 기능 변경은 새 값을 추정해 채우지 않고, 원천·확인 시각·등급을 함께 갖춘 레코드만 발행한다. 외부 예약 서비스의 로그인·결제 뒤 재고를 우회 수집하지 않는다.
